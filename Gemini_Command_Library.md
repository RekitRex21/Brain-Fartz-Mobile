## 🛠 Gemini CLI Commands
The following commands control the Gemini CLI environment:

- **`/help`**: Display the help menu with available commands and usage tips.
- **`/bug`**: Report a bug or provide feedback to the development team.
- **`/clear`**: Clear the current conversation context (start fresh).
- **`/exit`** (or **`/quit`**): Terminate the Gemini CLI session.
- **`/version`**: Display the current version of the Gemini CLI.

## 🤹 Skills Management

## 💻 Basic Termux Navigation
Essential commands for navigating the Android/Linux file system:

- **`ls`**: List files and directories in the current folder.
- **`cd <folder>`**: Change directory (e.g., `cd .obsidian`).
- **`cd ..`**: Go up one directory level.
- **`pwd`**: Print the current working directory path.
- **`cp <source> <dest>`**: Copy a file or folder.
- **`mv <source> <dest>`**: Move or rename a file.
- **`rm <file>`**: Remove (delete) a file.
- **`mkdir <name>`**: Create a new directory.

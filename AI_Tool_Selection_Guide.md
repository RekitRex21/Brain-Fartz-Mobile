# AI Tool Selection Guide

## How to Pick the Right AI Tool

| Task | Best AI Tool | Notes |
|------|--------------|-------|
| **Search / Web** | Perplexity | Up-to-date answers with citations |
| **Deep Research** | ChatGPT / Perplexity | Multi-step sourced insights |
| **Vision - Images** | Gemini | Analyze or create images |
| **Vision - Video** | Gemini | Review or create videos |
| **Camera Mode** | Google AI Studio | Real-time camera help |
| **Voice** | ChatGPT | Natural voice conversation |
| **File Uploads** | NumDex | Summarize documents |
| **Data Analysis** | Claude | Plot, analyze data (Code Interpreter) |
| **Canvas / Collaboration** | Claude | Draft, edit, build together |
| **Memory** | ChatGPT | Remembers your preferences |
| **Projects** | Perplexity | Visual project organization |
| **Scheduled Tasks** | ChatGPT | Reminders, automations |
| **Custom GPTs** | Gemini | Build task-specific assistants |
| **Agent Mode** | Perplexity | Multi-step task completion |
| **Connectors** | Zapier | Link to external apps |
| **Study / Learn** | GemZai | Structured lessons |
